# IPC Demo · 操作文档

本文说明如何运行本 Demo，并按界面逐步体验账号、配网、预览及 IPC 相关功能。  
集成细节见：[IPC_SDK_集成文档.md](./IPC_SDK_集成文档.md)

---

## 1. 运行前准备

1. 使用 Android Studio 打开工程根目录 `IPCDemo`。
2. 确认 `app/libs/` 已放入安全算法包 AAR。
3. 确认 IoT 平台 App 的包名为 `com.ipc.demo.set`，且已绑定当前调试证书 SHA256。
4. 配置 `local.properties` 中的 `sdk.dir`，以及 AppKey / AppSecret（若 Manifest 使用占位符）。
5. 真机调试建议使用 **ARM** 设备（工程 ABI：`armeabi-v7a` / `arm64-v8a`）；模拟器可能无法完整验证 P2P 预览。
6. 编译运行 Debug 包，启动页为 **登录**。

---

## 2. 整体流程

```text
登录 / 注册
  → 控制台：创建或选择家庭
  → EZ 或 AP 配网（可选）
  → 设备列表 → 点击摄像机
  → 实时预览面板
      ├─ 声音 / 清晰度 / 对讲 / 截图 / 录像 / 横屏
      ├─ 本地相册 / 消息 / 卡录像 / …
      ├─ 云台（设备支持时）
      ├─ 存储卡 / 卡录像 / 消息中心
      └─ 云存储 / 增值服务（仅支持云存储的设备显示）
```

---

## 3. 账号与控制台

### 3.1 登录 / 注册

| 步骤 | 操作 |
|------|------|
| 登录 | 输入国家码、账号（邮箱或手机号）、密码 → **登录** |
| 注册 | 登录页进入注册 → 获取验证码 → 完成注册 |
| 已登录 | 再次打开 App 会直接进入控制台 |

### 3.2 控制台（Main）

| 按钮 | 作用 |
|------|------|
| 创建家庭 | 填写家庭名称、城市等，创建后作为当前家庭 |
| 刷新家庭列表 | 拉取最新家庭数据 |
| 家庭列表 | 切换当前家庭（后续设备列表依赖当前家庭） |
| EZ 配网 | 进入智能配网页 |
| AP 配网 | 进入热点配网页 |
| 设备列表 | 查看当前家庭下设备 |
| 退出登录 | 清除登录态，返回登录页 |

> 未创建/未选择家庭时，配网与设备列表可能无法正常使用，请先完成家庭准备。

---

## 4. 配网

### 4.1 EZ 配网（智能配网）

1. 控制台点击 **EZ 配网**。
2. 输入手机当前 Wi-Fi 的 **SSID** 与 **密码**（一般需 2.4GHz，具体以设备说明书为准）。
3. 将摄像机置于配网模式（参考设备说明书，常见为指示灯快闪）。
4. 点击 **开始 EZ 配网**，等待成功提示。
5. 成功后进入设备列表，可见新设备。

### 4.2 AP 配网（热点配网）

1. 控制台点击 **AP 配网**。
2. 填写要连接的路由器 Wi-Fi 名称与密码。
3. 点击开始后，按提示到系统设置连接设备热点（常见名称形如 `SmartLife-XXXX`）。
4. 返回 App 完成激活。
5. 成功后到设备列表查看。

---

## 5. 设备列表

1. 控制台进入 **设备列表**。
2. 列表会按类型标注，例如：**摄像机**、**门铃/低功耗**、**其他设备**，并显示在线/离线。
3. 点击 **摄像机（IPC）** → 进入 **实时预览** 面板。
4. 非 IPC 设备点击会提示无法打开预览。

---

## 6. 实时预览面板（核心）

页面：`CameraPanelActivity`  
进入后自动连接 P2P 并开始预览；顶部可查看连接/预览状态。

### 6.1 预览区手势

| 手势 | 效果 |
|------|------|
| 双指捏合 | 连续缩放，约 1×～4× |
| 单击画面 | 在约 1× 与 2× 间切换 |
| 双击画面 | 在约 1× 与 3× 间切换 |

提示文案：「双指缩放 / 点击放大」。

### 6.2 竖屏操作栏

| 按钮 | 操作说明 |
|------|----------|
| 静音 / 开启声音 | 切换预览音频静音状态（默认可能为静音） |
| 高清 / 标清 | 切换清晰度 |
| 语音对讲 | 开始/结束对讲；首次需允许麦克风权限 |
| 视频通话 | 设备支持双向视频通话能力时显示 |
| 截图 | 保存到应用私有目录 `Android/data/<包名>/files/<设备ID>/`，成功 Toast；在 **本地相册** 查看 |
| 录像 / 停止录像 | 本地录制 MP4 至同上目录，停止后可在 **本地相册** 查看 |
| 横屏全屏（预览角标） | 进入横屏全屏预览 |
| 本地相册 | 浏览本设备截图与本地录像，点击可全屏预览 / 播放 |

### 6.3 横屏全屏预览

1. 点击预览区 **全屏** 图标，或走 `toggleFullscreen` 逻辑进入横屏。
2. 竖屏头部、功能入口隐藏；系统栏沉浸隐藏。
3. **左上角黑色返回按钮**：点击后退出全屏，回到竖屏正常预览。
4. 也可按手机 **系统返回键** 退出全屏（不会直接退出 Activity）。
5. **底部操作条**（横屏仍可用）：
   - 静音
   - 清晰度
   - 语音对讲
   - 截图
   - 录像  
   状态与竖屏按钮同步。

### 6.4 云台（PTZ）

- 仅当设备支持云台 DP 时显示 **云台** 入口。
- 进入后使用上 / 下 / 左 / 右控制；松手停止（Demo 以触摸按下/抬起发 DP）。

### 6.5 功能入口

| 入口 | 说明 | 显示条件 |
|------|------|----------|
| 存储卡 | SD 卡状态、容量、格式化、卡录像开关、水印等 | 一般常显（依赖设备 DP） |
| 卡录像 | 进入 SD 卡录像回放 + 时间轴 | 常显 |
| 消息中心 | 当天告警/检测消息，可看加密图、进视频消息 | 常显 |
| 云存储 | 云录像查询与播放 | **仅** `isSupportCloudStorage == true` |
| 增值服务 | 跳转 VAS / MiniApp 购买或服务页 | **与云存储同一能力门控** |

> 设备不支持云存储时，**不会显示**「云存储」「增值服务」按钮。这是预期行为，不是页面缺失。

## 7. 存储卡管理

路径：预览面板 → **存储卡**

| 操作 | 说明 |
|------|------|
| 查看状态 | 正常 / 异常 / 空间不足等 |
| 查看容量 | 已用 / 总量（以页面展示为准） |
| 格式化存储卡 | 清空卡内容，请确认后操作 |
| 卡录像开关 | 开启或关闭本地卡录像 |
| 水印 | 开关水印（设备支持时） |

---

## 8. 卡录像回放

路径：预览面板 → **卡录像**

1. 连接设备后查询有录像的日期。
2. 选择日期，加载当天录像片段。
3. 使用时间轴拖动定位；可播放 / 暂停 / 继续 / 停止。
4. 时间轴缩放：
   - **缩小**：偏向 12 小时视图
   - **放大**：偏向 24 小时视图  
5. 退出页面会释放 P2P / 播放资源。

---

## 9. 消息中心

路径：预览面板 → **消息中心**

1. 列表展示当天消息（移动侦测、告警等，以设备与开通能力为准）。
2. 图片类消息：可下载/查看加密图片（Demo 内已处理解密展示逻辑）。
3. 若含视频消息，进入 **视频消息** 页播放。

---

## 10. 云存储

路径：预览面板 → **云存储**（仅支持云存储的设备可见）

1. 进入后查询云存储服务状态：未开通 / 已开通 / 已过期。
2. 已开通时可按日期查看云录像时间轴并播放。
3. 可切换静音等（以页面按钮为准）。
4. 未开通时可配合 **增值服务** 入口跳转购买页（依赖 MiniApp）。

---

## 11. 增值服务（VAS）

路径：预览面板 → **增值服务**（与云存储同显隐规则）

1. 点击后尝试获取增值服务 URL，并通过 MiniApp 打开。
2. 若跳转失败，会提示并可能回退到云存储相关页。
3. 需保证已集成 MiniApp / bizkit，且 Application 已初始化 SoLoader。

---

## 12. 门铃呼叫（若设备支持）

1. Demo 在 Application 中注册了门铃监听。
2. 有来电时拉起呼叫界面：**接听** / **拒接** / **挂断**。
3. 接听后按门铃通话流程体验音视频（以设备能力为准）。

---

## 13. 推荐体验清单（验收用）

- [ ] 登录成功并创建/选择家庭  
- [ ] EZ 或 AP 配网成功，设备出现在列表且在线  
- [ ] 打开 IPC 预览有画面  
- [ ] 单击 / 双击 / 双指缩放生效  
- [ ] 开启声音、切换清晰度成功  
- [ ] 对讲可通（已授麦克风权限）  
- [ ] 截图、本地录像成功，并可在「本地相册」查看  
- [ ] 横屏全屏：底部可对讲/截图等；黑色返回恢复竖屏  
- [ ] 支持云台的设备可控制方向  
- [ ] 不支持云存储的设备：**看不到**云存储/增值服务  
- [ ] 支持云存储的设备：可进云存储页，状态查询正常  
- [ ] 卡录像时间轴可拖动播放  
- [ ] 消息中心可打开消息  

---

## 14. 操作注意

1. **网络**：预览依赖公网与 P2P，弱网可能黑屏或重连。  
2. **权限**：对讲务必授予麦克风；配网场景按系统要求开定位/Wi-Fi。  
3. **横屏返回**：优先点黑色返回或系统返回，避免误以为卡死。  
4. **云存储 UI**：以设备能力为准，勿与「功能没做」混淆。  
5. **密钥与签名**：包名、SHA256、AppKey 不一致会导致登录或设备相关接口失败。

## 15. 界面与代码对照（便于联调）

| 界面行为 | 代码位置 |
|----------|----------|
| 双击缩放 | `CameraPanelActivity.onDoubleTap` |
| 单击缩放 | `onSingleTapConfirmed` |
| 双指缩放 | `ScaleGestureDetector` |
| 进入/退出横屏 | `enterFullscreen` / `exitFullscreen` |
| 横屏返回按钮 | 布局 `btnFsBack` |
| 横屏操作条 | 布局 `fsActionBar`（`btnFsMute` 等） |
| 云存储显隐 | `isSupportCloudStorage(devId)` |

更完整的 API 与依赖说明见集成文档。
